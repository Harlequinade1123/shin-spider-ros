# reference/processing

Unmodified copies of the original Processing sketch files (`original_spider_controller`,
from `ExercisesInCreativeRobotics2`) that this package is ported from.

They are used only by `tools/java_golden/run.sh` to regenerate `test/golden/golden.txt`.
Only the files the generator reads are included (rendering, serial and gamepad-input files are not).
Do not edit them: the golden data must reflect the original behaviour.
